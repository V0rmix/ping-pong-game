# Ping Pong Game

Классическая аркада в стиле пинг-понга с реалистичной физикой мяча. Проект разработан на Python с использованием библиотеки Pygame.

## Управление

- **Игрок 1 (левая ракетка):**  
  W / S — перемещение вверх/вниз  
- **Игрок 2 (правая ракетка):**  
  Стрелка ↑ / Стрелка ↓ — перемещение вверх/вниз  
- **ESC** — выход из игры
## Особенности
- Фоновое изображение игрового стола
- Система подсчёта очков для двух игроков
- Центральная разделительная линия поля
- Автоматический респаун мяча после гола
